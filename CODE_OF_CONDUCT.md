# Code of Conduct

## The short version

Be decent. Assume good faith. Critique code, not people.

## Expected behaviour

- Give feedback on the work, with reasons. "This will break under concurrent writes
  because…" is useful; "this is bad" is not.
- Accept that a change can be well-written and still be declined for scope reasons.
- Ask when you do not understand something. This project keeps ADRs precisely so the
  reasoning is inspectable rather than folklore.

## Unacceptable behaviour

Harassment, personal attacks, discriminatory language, sustained disruption, publishing
private information, or unwelcome attention of any kind.

## Scope

Applies in issues, pull requests, discussions, commit messages, and any space where you are
representing the project.

## Enforcement

Report concerns privately to the maintainer via GitHub. Reports are handled confidentially.
Consequences range from a warning to a permanent ban, depending on severity — the
maintainer decides, and will explain the reasoning.

This is a small project. In practice, "be decent" covers it.
